## 🎮 Sobre el juego
**AI or Human?** es un proyecto interactivo desarrollado en Unity que pone a prueba la capacidad de los jugadores para distinguir entre creaciones hechas por inteligencia artificial y contenido generado por humanos. 

---

## 🛠️ Tecnologías y Requisitos
* **Motor de juego:** Unity (Versión recomendada: `2020.3.49f1`)
* **Lenguaje:** C#
* **Control de versiones:** Git y GitHub
